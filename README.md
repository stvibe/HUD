# RPG HUD, технический прототип v0.1

Установка: распаковать каталог `rpg-hud` в `SillyTavern/public/scripts/extensions/third-party/`, перезапустить/обновить SillyTavern.

Реализовано: плавающая панель, сохранение полей в chatMetadata, дата, локация/прибытие, ручной d5, ручное изменение инвентаря, акцент, разбор RPG_STATE с базовой валидацией, защита от повторного применения по сообщению и свайпу.

Тег нарратора:

```html
<!-- RPG_STATE
{"elapsed_minutes":45,"destination":"Торонто"}
-->
```

Важно: тег пока НЕ скрывается из видимого сообщения, промпт нарратору НЕ внедряется, результат кубика НЕ отправляется автоматически. Не реализованы беременность, NPC, лорбук, контекстная оценка времени, транзакции, полноценный откат при редактировании/удалении и сложных свайпах. Свайп-откат здесь экспериментальный и может быть некорректен при последовательных изменениях. Это прототип, а не готовое расширение; протестировать в реальном SillyTavern здесь невозможно.
